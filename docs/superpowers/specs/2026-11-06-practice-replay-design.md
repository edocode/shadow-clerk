# 語学練習で聞き直した文を Claude に伝える — 設計

日付: 2026-11-06
状態: 下書き（承認待ち）

## 目的（なぜ作るか）

語学練習（clerk-practice）で、AI分析ペインの「🔊 英語」を押して同じ文を何度も聞き直すのは、
その文が聞き取れなかった証拠になる。この証拠を Claude に渡すと、次の二つに使える。

- 繰り返し練習する価値がある文として扱う。
- 似た音の問題を、ゆっくり発声させるなど次の出し方を変える。

ペルソナによっては、返すメッセージの言い回しや雰囲気の味付けにも使える。

## ゴール

- 🔊 で再生した英文ごとに、練習セッション内の回数を数える。
- 🔊 を押した時点で、Claude Code の PTY（AI コンソール）へ一行を送り、「聞き直している」ことと回数を伝える。
- 送るのは押した時点の一回だけ。Claude が次の文を出すときに、その情報を見られる状態にする。

## ノンゴール（今回やらないこと）

- 練習をまたいだ集計や、履歴の保存。
- 聞き直し回数の画面表示や分析グラフ。
- 聞き直しの有無で発音評価を自動で変えること（Claude の判断に任せる）。
- 聞き直しをユーザーの音声入力として扱うこと。

## 失敗の形（やってはいけないこと）

- 🔊 を押しただけで、会話の流れを乱すような長い文を Claude に入れてしまうこと。
- 聞き直しの一行が、ユーザーの発話と区別できず、[自分] の発言として transcript に残ること。
- 練習の PTY が無いときに、別の役割の PTY へ誤って送ること。

## 制約

- 英文の同一性は、英文をハッシュにした値で判定する。ハッシュは同じ文を同じ項目として数えるための鍵で、内容の確認には使わない。
- カウントはダッシュボードのタブのメモリ内で行う。永続化しない（ページを読み直すとリセットされる）。
- PTY への入力は既存の `POST /api/console/input` を使う（`_daemon_dashboard_ops_console.py` の `_console_input`）。
- 🔊 の処理は `src/shadow_clerk/_daemon_dashboard_js_speech.py`（`SAY_TAG` 付近）にある。
- clerk-practice スキルを変えるので、`metadata.version` を上げる（CLAUDE.md の方針）。

## 設計

### 1. カウント（ダッシュボードの JS）

- 🔊 の押下時に、読み上げる英文の正規化済みテキストからハッシュ値を作る（SHA-256 の先頭など、衝突しにくい短い形）。
- ハッシュ → 回数のマップを、タブのメモリに持つ。
- 「練習セッション」の区切りは、練習の PTY を起動した時点から。停止・再起動でリセットする。

### 2. 伝達（PTY への一行）

- 押した時点で、練習の PTY に一行を送る。例:
  `[練習] 聞き直し: 「<英文>」 （この文は N 回目）`
- 英文は PTY に送るとき、長さの上限（例: 200 文字）で切る。
- 改行や制御文字は除く。
- Enter を付けて送るかどうかは実装時に確認する（送ると Claude の入力として即座に処理される）。
- 送り先の role は、練習の PTY の role を使う。練習の PTY が起動していなければ送らず、ダッシュボードに出すだけにする。

### 3. Claude 側の扱い（clerk-practice スキル）

- 聞き直しの一行を受けたら、その文を次の練習候補に入れる。
- 回数が多い文は、似た音の練習として、ゆっくり発声させる指示を次の出し方に含める。
- ペルソナの味付けは、スキルの指示に従う範囲で任せる（スキル本体に固定の語彙は足さない）。

## 設計上の判断（私の判断で決めた点）

以下は、ご確認の上で変更できます。

- 数える単位は「英文ごと」（ハッシュ化した英文）。
- 送るタイミングは「🔊 を押した時点」。
- 送る先は練習の PTY（既存の `/api/console/input`）。
- カウントは練習セッションのメモリ内のみ。永続化しない。
- 英文の長さの上限は 200 文字。
- 聞き直しの一行には、ユーザーの発話と区別できる [練習] の接頭辞を付ける。

## 未決（実装前に確認したいこと）

- 練習セッションが動いている PTY の role は、assistant と talk のどちらか。実装時に確認する。
- Enter を付けて送るかどうか（即時に処理させるか、入力欄に残すか）。
- 聞き直しの一行を Claude が見たときに、会話の transcript にも残すかどうか。残すなら [自分] とは別の記録にする。
