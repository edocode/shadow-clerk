# 日本語の練習

日本語（`ja`）を練習するときに、共通の [SKILL.md](../SKILL.md) と合わせて読む。
開始・終了、聞き取り言語の切り替え、練習時間、記録の更新は共通手順に従う。
学習者の母語は日本語ではない。説明は学習者の母語で行う。

## 教材と読み方

- 表記は漢字かな交じりにし、読みはひらがなで添える（`切手（きって）`）。ローマ字は学習者が求めたときだけ添える。
- 単語単体や単語の羅列では出さず、一息で言える短い文にする。対象語を文頭に置かない。
  キャリア文（`わたしは きって と いいました`）を使ってよい。
- 発音のお手本の例: `{"text":"切手を買いました。","lang":"ja","display":"(Q1: I bought stamps.)"}`。
- 以下の例は形式を示すもの。課題文は毎回その場で作り、固定の例文一覧として順に出題しない。

## 日本語の音素フィードバック

daemon は日本語を**かな（モーラ）単位**で突き合わせる。英語の IPA とは別の経路で、
英語の音の対立・正規化の制約・実測値（9.1% など）は日本語に適用しない。

API の使い方は英語と同じ。[english-practice.md](english-practice.md) の「英語の音素フィードバック」のうち、
**状態の確認、手順（1〜7）、拒否の扱い、`state` が `loading` のとき、attempt が見つからないとき、終わったら**に従う
（`lang` は `ja`）。課題の出し方・読み方・書き方は、英語のものではなく以下に従う。

### 記号

`expected` と `ops` の記号は**モーラ**（ひらがな）。

| 記号 | 意味 |
|---|---|
| `きょ` `しゅ` | 拗音は1モーラ |
| `っ` | 促音 |
| `ん` | 撥音 |
| `ー` | 長音。書き方（おう / おお / ー）によらず `ー` |
| `し̥` `く̥` | 無声化しうる位置（記号の下に小さな丸）。所見の対象にしない（下記） |

助詞の「は」「へ」は表記のまま（`は` `へ`）、「を」は `お` になる。

### 課題の出し方

- **測れる対立**: 促音の有無（`きって` / `きて`）、長音の有無（`とおり` / `とり`、`おばあさん` / `おばさん`）、
  拗音の分離（`びょういん` / `びよういん`）、撥音（`せんえん` / `せねん`）、ら行とだ行（`らいねん` / `だいねん`）、
  清音と濁音（`ざっし` / `さっし`）、つ と ち（`つくえ` / `ちくえ`）
- **測れないもの**: 高低アクセント（モーラ列に現れない）、助詞「は」を ha と読む誤り（モデルが表記どおりに書く）。
  これらは「音声認識だけで判定する」でも判定できないので、お手本を聞かせて真似てもらうだけにする
- **「にほん」は出さない。** 正しく読んでも毎回「にっぽん」と出る（モデルの癖）
- **読みが割れる漢字を避ける。** 「私」は `わたくし`、「今日」は `こんにち` と読まれることがある。
  POST の応答の `expected` が意図した読みかを必ず確かめ、違えばその語をかなで書いて送り直す
- 課題文に**数字を書かない**（`みっつ` のようにかなで書く）
- `focus` は**語ではなくモーラ**で指定し、`expected` に出てくる記号をそのまま書く（`{"word":"切手","phoneme":"っ"}`）。
  語は応答の `expected[].word` の区切りで書く（「行きました」は1語）。無声化の印が付いたモーラは `focus` にしない

```
curl -s -X POST "http://localhost:8765/api/pronounce" -H 'Content-Type: application/json' -d '{"text":"わたしは切手を買いました。","lang":"ja","focus":[{"word":"切手","phoneme":"っ"}]}'
```

### 読み方

- **`focus: true` の op だけにコメントする。** それ以外はフロア誤差。ネイティブの文の読み上げでも、
  モーラ誤り率は 4〜6% ある
- **無声化の印（`し̥` など）のモーラの `sub` / `del` は所見にしない。** 無声化した音はモデルに別の音として聞こえる
  （「ました」が「ますた」）。`し̥` と `す` の違いは daemon が `same` にしてある
- 読み取り方の目安:
  - 促音が抜けた: `del`（`っ` → なし）。余計に入った: `ins`（なし → `っ`）
  - 長音が抜けた: `del`（`ー` → なし）。余計に伸ばした: `ins`（なし → `ー`）
  - 拗音が割れた: `sub`（`びょ` → `び`）と `ins`（なし → `よ`）が続く
  - 撥音が次の音とつながった: `sub`（`ん` → `ね` など）と、次の母音の `del`
- **文頭・文末の語の `del` は所見にしない**（録音の端が欠けることがある。`trimmed: true` のときは特に）
- **この1回の発話の所見として言う。** 「あなたの促音は」と傾向で断定しない
- **調音の助言は定型の範囲に留める**（「小さい っ の分だけ、一拍止める」「ー の分だけ、一拍のばす」）。
  拍（モーラ）の長さとして伝えると分かりやすい

### 書く

Analysis の `結果` の列に ○△× を書かない。観測をそのまま書く:

| 語 | 読み | 意味 | 結果 |
|---|---|---|---|
| 切手 | きって | stamp | っ が出ていない |
| 病院 | びょういん | hospital | びょ が び と よ に分かれている |

- `focus` の op が `same` なら「出ていた」。`sub` なら「<期待> が <実測> 寄り」。`del` なら「出ていない」。
  `ins` なら「<語> の <位置> に <音> が入っている」
- **「完璧」「正解」と書かない**
- Advice には**外したモーラと位置**を書く
- 試した語・文は、うまくいったものも含めて全部 Analysis に残す

## 会話中の音素解析

英語と同じく `free` で預けられる（`{"free":true,"lang":"ja"}`）。手順は english-practice.md の「会話中の音素解析」に従う。

- **拾うのは促音・長音の有無と、拗音の分離だけ。** それ以外の差分はフロア誤差として扱う
- 無声化の印のモーラは拾わない
- 期待文は文字起こしなので、崩れた音が別の語として認識されると差分は出ない（`きって` が `きて` と書き起こされると、期待文も `きて` になる）。
  文脈から見て語がすり替わっているときは、それ自体を所見として扱ってよい
- 指摘は1ターンに1つまで、文法の直しのあとに短く添える

## 日本語の記録例

```
curl -s -X POST "http://localhost:8765/api/generated" -H 'Content-Type: application/json' -d '{"kind":"analysis","mode":"append","text":"\n## 10:20 発音 小さい っ\n\n| 語 | 読み | 意味 | 結果 |\n|---|---|---|---|\n| 切手 | きって | stamp |  |\n| 来て | きて | come |  |\n\n- 🔊[ja] わたしは切手を買いました。\n- 対象語: 切手（きって）・ 来て（きて）\n"}'
```

```
curl -s -X POST "http://localhost:8765/api/generated" -H 'Content-Type: application/json' -d '{"kind":"advice","mode":"replace","text":"# Corrections\n\n## Focus today\n- 小さい っ: hold for one beat before the next sound\n\n## Latest\n| 語 | 読み | 結果 | ポイント |\n|---|---|---|---|\n| 切手 | きって | っ was missing | き・(pause)・て — three beats, not two |\n\n## Model\n- 🔊[ja] わたしは切手を買いました。\n"}'
```
