# voicevox-sing — ボイスボックスで歌を作って歌わせる

Claude が歌詞とメロディ（音程と長さ）を書き、VOICEVOX エンジンの歌唱 API に渡して鳴らす。
clerk-talk の `/api/say` は読み上げ専用で歌えない。歌はエンジン（既定 `http://localhost:50021`）へ直接送る。

## 手順

1. エンジンの確認: `curl -s "http://localhost:50021/version"`。応答が無ければ歌えないと伝えて終える。
2. 歌う声を選ぶ。`curl -s "http://localhost:50021/singers"` の `type: frame_decode` のスタイル id が声。
   既定は玄野武宏ノーマル（3011）。男声は MIDI ノート 55〜72 あたりが無理なく歌える。
   `type: sing` のスタイル（例: 波音リツ 6000）は音程の下書き（`--query-speaker`）に使うだけで、声ではない。
3. 楽譜 JSON を書く（形式は `sing.py` の冒頭に書いてある）。歌詞は**ひらがな 1 モーラ = 1 音符**。
   - 拗音は 1 音符にまとめる（「しゅ」「きゃ」）。促音「っ」と長音「ー」は単独の音符にしない。言い換える
   - 助詞の「は」「へ」は表記どおりの音（ha / he）で歌われる。「わ」「え」に書き換える
   - 休符は `[null, null, フレーム数]`
4. 実行: `python3 -I <このスキルのディレクトリ>/sing.py score.json 曲名.wav --play`
   （Claude Code なら `~/.claude/skills/voicevox-sing/sing.py`）
   作業ファイルはスクラッチパッドに置く。歌うたびに、作業ディレクトリの `songs/曲名.mp3` にも保存される
   （`--mp3-dir` で変更、空文字で無効）。wav のファイル名は日本語の曲名にしてよい。
5. 感想を聞き、直す。

## 曲作りのコツ（試して分かったこと）

- 全部同じ長さの音符だと「お経」になる。14 / 28 / 56 フレームを混ぜて緩急をつける
- **全部の言葉を伸ばさない**（「メリハリがない」と指摘された）。24 フレーム固定ではなく、12 を主体に 24 を混ぜ、
  フレーズの最後だけ 48〜120 で伸ばす。短い音（30 フレーム以下）は音符の後ろに 5 フレームほどの休符を足すと歯切れが出る。
  1 小節 = 192 フレームなので、12×n + 24×m + 最後の長音で合計が 192 になるよう組む
- サビは Aメロより高くしてよいが、**高音に頼り切らない**（「高音に頼りがち」と指摘された）。男声なら MIDI 72 まで、
  サビ全体を高く張り付かせず、山と谷をつくる。最後の音は主音に戻して長く伸ばす
- **声を変えたら音域を確認する**。男声の旋律に +12 してずんだもん（3003）で歌わせたら「声が高すぎ」と言われた。
  移調は伴奏の和音と調を揃えること（半音ずらすと不協和になる。サビだけ下げるなら、音階の度数でずらす）
- **歌詞は話題の順番と場所を揃える**。同じ場所・同じ話題の歌詞は連続させる（A 町の話を、B 町の後にもう一度出すと
  「文脈がおかしい」と言われた）。題材を並べるときは、場所のまとまりごとに章を分ける
- 掛け声の合いの手や短い題名など、耳に残る繰り返しを入れると曲らしくなる
- 1 フレーム ≒ 10.7ms。14 フレームで約 0.15 秒。テンションの高い曲は 12〜14、しっとりは 20〜28
- 既存曲の歌詞は書かない。替え歌は元の歌詞を使わず、題材とノリだけ借りる

## clerk-talk 中に歌うとき

- 歌う前に `/api/say` で一言だけ予告し、`/api/speaking` が false になってから再生する（読み上げと重ねない）
- 再生中はユーザーが割り込めない。1 曲は長くても 30 秒ほどにする（「長くてもいい」と言われたら延ばす）
- 再生後、`/api/say` で感想を聞く

## バンド伴奏をつける（任意）

`band_example.py` は、歌のフレーム数に合わせて GM 音源（ドラム・ベース・ギター・エレピ）の伴奏を鳴らし、歌と混ぜて MP3 にする実例。
SoundFont 合成には `tinysoundfont` を使う。システムには入れず、仮想環境で `uv pip install --no-deps tinysoundfont numpy cffi`
（依存の pyaudio はビルドに失敗するので `--no-deps`。再生は `aplay` を使う）。
音源は `/usr/share/sounds/sf2/TimGM6mb.sf2`。1 小節 = 192 フレームに歌を揃えると伴奏と合う。

`band_example.py` は伴奏の `back.wav` を作るところまで。歌（`vocal.wav`）と混ぜるときは ffmpeg を使う。
歌は 44.1kHz のステレオにそろえて持ち上げ、伴奏は下げる:

```
ffmpeg -y -i vocal.wav -i back.wav -filter_complex "[0:a]aformat=sample_rates=44100:channel_layouts=stereo,volume=1.6[v];[1:a]volume=0.45[b];[v][b]amix=inputs=2:duration=longest:normalize=0,alimiter=limit=0.95" mix.wav
```

歌い出しは、イントロの 1 小節の休符の後ろに、`sing.py` が足す先頭の 20 フレームを加えた位置から。伴奏側の `t0` は
その分（20 / 93.75 秒）ずらす。
