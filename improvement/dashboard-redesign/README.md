# ダッシュボード刷新: 一般の人にもわかりやすい UI

ダッシュボードを、shadow-clerk を初めて使う人にもわかる画面に作り直す計画。この下には、合意した試作と、
現行のエンドポイントを新 UI のどこに置くかの対応表がある（2026-10-31 時点の origin/main・#114 マージ後が基準）。

- `dashboard-friendly-ui-interactive.html` — 試作。ブラウザで開くと操作できる（`python -m http.server` などで配信する）
- `endpoint-mapping.html` — `_daemon_dashboard_base.py` の全ルートの対応表。割当済 / 部分的 / 未割当 / UI 外

## 試作で決めたこと

- ヘッダ: 状態表示、「会議開始」トグル（開始モーダルで会議名・言語・AI アシスタント）、翻訳、Claude と会議、
  自分の声 / 相手の声のミュート（録音は止めない。止めるのはミュート）、その他メニュー、🪟 表示、かんたん / くわしく
- 表示の切り替え: 文字起こし / ＋翻訳 / 翻訳だけ / 議事録・AI のアドバイスを大きく / AI アシスタントの画面。
  AI を大きくするときは右ペインそのものが中央に来て、アドバイスと分析を縦 2 カラム（狭いときは上下）に並べる
- 行の選択（クリック・Shift+クリック）から、会議として切り出す・話した人を直す・削除する
- 今日のメモは会話のまとまりごとに区切って見せ、まとまりごとに切り出せる
- 議事録・翻訳は「コピー / 再読み込み / 作り直す / 開く」を残す
- Claude と会議は、チャットに入る前にモード（会議の種類）を選ぶ
- 会議ごとの設定は、会議をチェックで選んでまとめて値を設定する（パターンのルールは作らない）。絞り込みはフィルタで
- 検索は現行の条件（キーワード・対象・年 / 月 / 日 / 時・200 件）のまま、結果を会議ごとにまとめて本文を見せる

## 実装の進め方

各機能を実装するときは、まず現行のダッシュボードを実際に操作して確かめ、対応する JS とサーバー側の処理を読んでから作る。
試作は何度か API にできない操作を描いていた（会議設定の項目、AI アシスタントが同時に1つだけであること、
沈黙で分ける規則、Claude の声の届け先の一覧）。現行より不便にしない、API にできないことを描かない。

## 残っていること

`/` が新 UI、`/legacy` が現行の UI になった（`/next` は `/` へリダイレクト）。対応表のルートはすべて新 UI から呼ぶか、
UI 外（スキル・拡張・clerk-util）として `tests/test_next_endpoint_coverage.py` の一覧にある。以前ここにあった
未定の置き場所（声紋・話者の名前付け・スキル導入 / 更新・ファイル名リンク・参加者・モード削除・音声コマンドの応答）と、
会議ごとの `analyze` の 3 状態化は済んだ。

- Claude と会議の浮かぶ吹き出しパネル（試作。transcript と `/api/speaking` から作る）。いまは中央に記録と「会議中」の帯
- プロンプトなしの起動（以前のセッションを `/resume` する）。現行の `launchConsole` にしかない
- `/legacy` と流用しなかった現行モジュールの削除。ユーザーがしばらく使ってから別の計画で行う
- 後回しにした小さな直し（進捗台帳の「deferred → final fix pass」）:
  - 会議ごとの設定: 読み込みの失敗が「該当なし」に見える、選び直すと未保存の変更が消える、テキスト欄の Enter で保存しない、
    公開先を変えずに Notion の URL を消せない、「まとめて開く」が行の ⚙ と同じ `data-act=cfg` を使う、list の古い `typeof` ガード
  - Claude と会議: 再生していないのに覚えた届け先アプリが選ばれる、見ている会議と記録中の会議が違うときの帯の文言、
    帯に言語・クレジットが出ない、消したプリセットの値がフォームに残る、色の直書きと現行モーダル CSS の写し
  - その他メニュー: 「全文を見る」が くわしく を覚えてしまう、かんたん ではトーストの後に短い応答を見られない
  - 話者の名前付け: 付け直しの `grpSuggest` を埋めない、付け直しの後にグループを読み直さない、議事録の作り直しの開始に
    失敗すると取り消しが消える、`naming_path` が無いときも id を返す、PEP8 の空行
