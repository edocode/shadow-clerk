バックエンドの変更が要るもの

会議ごとの analyze を 3 状態（既定 / オン / オフ）にする

  • 現状：MeetingConfig.DEFAULTS["analyze"] が True のため、「書いていない」と「true と書いた」を区別できない。自動起動は auto_analyze and analyze なので、会議ごとの設定は止める方向にしか効かない
  • domain/meeting_config.py：analyze の既定を「未指定」にし、resolve で未指定・true・false を区別して返す
  • _daemon_recorder_command.py _maybe_start_analysis：true なら auto_analyze がオフでも起動、false なら起動しない、未指定なら auto_analyze に従う
  • MeetingSettings.parse / POST /api/meeting-settings：None は「変えない」なので、既定に戻す値（例 "default"）を受けてキーを消す。GET も 3 状態で返す
  • GET /api/meeting-config/resolve（clerk-meeting-helper が「analyze が偽なら監視しない」に使う）：明示的なオフのときだけ false を返す。手動で「会議を見て」と頼まれた場合は、自動起動の設定に関係なく監視する
